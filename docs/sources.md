# Sources consulted

| Topic | Link | Date consulted | What I learned |
|---|---|---|---|
| HTTP log format | https://httpd.apache.org/docs/2.4/logs.html | 18/11/2026 | Each part of a log entry represents something: the IP address of the client, the availability of the requested piece of information, the userid of the person requesting, the time the request was received and its format, the request itself, the status code (successful requests begin with 2xx, redirected pages with 3xx, failed ones with 4xx or 5xx), the size of the object returned to the client, the page the visitor came from, and finally the software the visitor uses. |
| Date parsing | https://docs.python.org/3/library/datetime.html | 18/11/2026 | Python can read date and time using the built-in toolkit "import datetime as dt", with "strptime" to parse (turn text into datetime), "strftime" to do the reverse, and "isoformat()" for the standard ISO 8601 text. Parsing a day of the month without a year raises an error in modern Python, and SSH lines have no year, so we will add one ourselves before parsing. Python also raises an error when comparing or subtracting an aware and a naive datetime (a naive datetime has no timezone, unlike an aware one), so we make every timestamp aware in UTC. |
| Common schema | https://www.elastic.co/guide/en/ecs/current/index.html | 18/11/2026 | ECS defines a shared set of field names and data types for event data such as logs. The goal is that events from different sources look alike, and that is normalization. |
| SQLite | https://docs.python.org/3/library/sqlite3.html | 18/11/2026 | SQLite is a small database that lives in one file on your computer, with no server to install. Python includes it, so you only need "import sqlite3". We must be aware of SQL injection, a vulnerability. To protect against it we put ? placeholders in the query and pass the values separately (never build SQL queries by pasting Python values into a string). |
| CSV injection | https://owasp.org/www-community/attacks/CSV_Injection | 18/11/2026 | CSV injection is an attack that happens when an application puts untrusted input into a CSV file. To prevent it, put a ' in front of any risky cell before it goes into the CSV. A spreadsheet looks at the first character of a cell: if it is =, it thinks it is a formula and calculates it, but if it is ', it displays the cell as plain text. |
| Reference project (study only) | https://github.com/gaston-dev-web/mini-siem | 20/11/2026 | A larger SIEM example (MIT licence). Same stages as MiniSOC: parsing, normalization, SQLite, correlation rules, dashboard. I study it but do not copy code. |
| Sample Apache logs | https://github.com/elastic/examples/blob/master/Common%20Data%20Formats/apache_logs/apache_logs | 20/11/2026 | Public Apache access-log sample (Combined format), to test the HTTP parser.  |
