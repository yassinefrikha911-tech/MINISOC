# MiniSOC

Defensive log monitoring lab project. It imports SSH and HTTP logs, normalizes them into events, applies correlation rules, and shows alerts in a dashboard.

Lab use only: synthetic data, no intrusive agent, no automatic response.

## Status
- Week 1 (planning): done. See the `docs` folder.

## Stack
Python, Streamlit, SQLite, HTML. Export in CSV.
